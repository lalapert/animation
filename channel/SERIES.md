## 0. 절대 규칙: 게시물에 한국어 금지

시청자 기준은 해외다. 밖으로 나가는 것에는 한국어가 한 글자도 들어가지 않는다.

- 대상: 영상 속 글자(간판, 자막, 소품), 대사와 음성, `.srt`, 제목, 설명, 해시태그, 태그, 게시물 본문, 프로필 사진, 배너, 채널 소개, 파일 이름.
- 한국을 떠올리게 하는 설정도 이야기에 쓰지 않는다(인물 출신, 지명, 음식, 문화 농담). 인물 이름은 Rae, Pip, Dennis, MAGS.
- 자동 점검: 게시 전에 `python3 channel/tools/check_english.py <파일들>`이 통과해야 한다(한글 글자가 하나라도 있으면 실패). 최종 음성은 ElevenLabs 받아쓰기의 언어 판정이 영어(`eng`)여야 한다.
- 유튜브 자동 더빙이나 인스타 Meta AI 번역을 켜게 되면 **한국어는 대상 언어에서 뺀다.**
- 저장소 안 작업 문서(이 파일 같은 것)는 작가님이 읽는 용도라 한국어로 둔다. 게시되지 않는다.

## 2. 목소리 규칙

- 주인공: Rae = Kar2, Pip = Win2, 모델 eleven_v4.
- 반복 등장 인물(3화 이상): ElevenLabs 보이스 디자인으로 만들어 저장하고, 보이스 ID를 위 표에 적어 고정한다. 처음 둘은 MAGS, Dennis.
- 한 번만 나오는 손님: ElevenLabs 기본 보이스. 같은 보이스를 연달아 쓰지 않는다.
- **주의: Kar2와 Win2는 같은 설명으로 만든 보이스다.** 두 샘플의 음높이도 거의 같다(중앙값 242 Hz와 235 Hz). 받아쓰기에서는 둘 다 영어로 판정됐다(확률 0.99). 시트콤에서 두 사람 목소리가 구별되지 않으면 누가 말하는지 헷갈린다. 대책:
  1. 연기 차이: Rae는 낮고 느리고 건조하게(안정성 높게, v4 오디오 태그로 deadpan, sigh), Pip는 빠르고 높게(안정성 낮게, excited).
  2. 화면 차이: 말하는 사람의 입만 움직이고, 자막 색을 인물별로 다르게 한다.
  3. 그래도 부족하면 Rae 대사만 후처리로 1~2반음 낮춘다(우리 믹서에서 처리).
  - 1화 제작 전에 두 사람이 주고받는 대사 샘플을 만들어 작가님이 듣고 정한다.

## 3. 해외 노출

**제작에서 하는 것**
- 첫 1~2초에 그림으로 질문을 던진다(자동문 + 이상한 손님).
- 자막을 영상에 박는다(무음 시청 대비).
- 농담은 어느 나라에서나 통하는 경험(손님 응대, 야간 근무, 상사)에 둔다. 말장난과 특정 문화 농담은 피한다.
- 게시 시각 09:00 KST = 미국 동부 전날 저녁 7시, 서부 오후 4시.
- 제목, 설명, 해시태그 모두 영어. 해시태그는 3~5개(`#animation #cartoon #scifi #comedy #shorts`).

**작가님이 한 번 설정할 것** (`CHANNEL_PROFILE.md` 5절)

## 4. 제작 순서

1. 캐릭터 디자인 시트 v1 → 작가님 확인 (지금 단계)
2. 보이스: Kar2·Win2 주고받기 샘플, MAGS·Dennis 보이스 디자인 → 작가님 확인
3. 프로필 사진과 배너(확정된 캐릭터로)
4. 캐릭터 리그(입 모양 5종, 눈 깜빡임, 몸 흔들림), 가게 세트
5. 1화, 2화 제작 → 제작 지침(`PRODUCTION.md`) 새로 쓰기 → 예약 작업을 화·목·토로 바꿔 다시 켠다

**그림 엔진:** 우리 코드로 직접 그린다(굵은 외곽선, 평면 채색에 그림자 한 단, 2D 캔버스). lemo-opuscar 라이브러리의 엔진은 쓰지 않는다.

**립싱크:** ElevenLabs 타임스탬프(글자 단위 시간)로 입 모양 5종(닫힘, 조금, 크게, 오·우, 이·에)을 고른다.
