# 채널 이름·핸들·소개 (안)

작성 2026-11-06. 채널을 우주 시트콤 툰 한 시리즈로 바꾸면서 다시 썼다. 시리즈 설정은 `SERIES.md`.

## 1. 결론: 채널 이름 = 시리즈 이름 **Void Mart**

| | 유튜브 | 인스타그램 |
|---|---|---|
| 이름 | Void Mart | Void Mart \| animated sitcom |
| 핸들 / 사용자 이름 | @voidmart | voidmart |
| 대체 핸들 (앞이 막히면 순서대로) | @voidmart.tv → @voidmart.toon → @thevoidmart → @voidmartshow | voidmart.tv → voidmart.toon → thevoidmart → voidmartshow |

- 두 플랫폼에서 철자를 똑같이 맞출 수 있게 영문 소문자와 마침표만 썼다. 하이픈은 유튜브만 허용하므로 쓰지 않는다.
- **사용 가능 여부는 확인하지 못했다.** 이 환경에서는 유튜브와 인스타 가입 여부를 조회할 방법이 없다. 웹 검색으로는 "Void Mart"라는 이름의 애니메이션 채널이나 계정은 찾지 못했다(작은 계정은 검색에 안 잡힐 수 있음). 유튜브 스튜디오와 인스타 앱에서 직접 입력해 보고, 막히면 위 대체 핸들 순서로 간다. 대체 핸들도 두 플랫폼에서 같은 것으로 맞춘다.

**왜 시리즈 이름을 채널 이름으로:** 쇼츠 시청자는 스튜디오가 아니라 캐릭터와 세계를 구독한다. 채널 이름만 보고 무슨 채널인지 알 수 있어야 구독 전환이 생긴다. "Paper Almanac"은 수채·계절 느낌이라 우주 시트콤과 맞지 않는다.

**약한 점:** 나중에 다른 그림체 시리즈(SERIES.md 6절)를 시작하면 이 이름과 안 맞는다. 그때는 같은 채널에 섞지 말고 채널을 따로 여는 쪽을 권한다. 장르가 다른 영상을 한 채널에 섞으면 구독자가 기대한 것과 다른 영상이 나와서 이탈이 생긴다.

## 2. 유튜브

**채널 이름:** Void Mart (유튜브 이름 한도 약 100자, 핸들 3~30자. 제3자 정리 자료 기준이라 유튜브 스튜디오에서 다시 확인 필요)

**설명** (한도 1,000자, 이 안은 531자. 첫 150자 정도가 "더보기" 앞에 보이므로 첫 문장에 설정을 넣었다):

```
The last convenience store before the edge of the universe. Two night-shift clerks. Every customer is a problem.

Meet the night shift:
Rae has worked nights here for three years. She has seen everything and refunds nothing.
Bomi started this week. She wants to be friends with every customer, including the ones made of fire.
MAGS is the store's AI manager. Always watching. Always upselling.

An original animated sitcom in 45-second episodes. New episodes three times a week.

Every frame is drawn in code. Voices are synthetic.
```

- 마지막 줄(제작 방식 공개)은 선택. 애니메이션 커뮤니티는 AI 반감이 크다. 그림은 이미지 생성 AI가 아니라 코드로 그린 것이고, 목소리만 합성이다. 먼저 밝혀 두면 "AI 영상"이라는 댓글 공격을 줄일 수 있다(추측). 빼고 싶으면 빼도 된다.
- 업무 연락 이메일을 넣으려면 설명 끝에 `Business: <주소>`를 추가한다. 개인 주소는 넣지 않는 걸 권한다.

**키워드 (채널 설정 > 기본 정보):**
```
animated sitcom, animation, cartoon, sci-fi comedy, space comedy, adult animation, animated shorts, original animation, convenience store, night shift, retail humor, aliens, shorts
```

**재생목록:** `Void Mart — Season 1`, `MAGS moments`(매니저 장면 모음, 10화 이후).

**쇼츠 제목 형식:** `<에피소드 제목> | Void Mart #shorts` (예: `Exact Change | Void Mart #shorts`)

**쇼츠 설명 형식:**
```
<손님이 원하는 것 한 줄>. <펀치라인은 숨기고 질문 한 줄>?
Void Mart, episode <N>.

#animation #cartoon #scifi #comedy #shorts
```

## 3. 인스타그램

**사용자 이름:** voidmart (한도 30자)

**이름:** `Void Mart | animated sitcom` (27자. 이름 칸은 검색에 잡히므로 "animated sitcom"을 넣었다. 한도는 30자라는 자료와 64자라는 자료가 엇갈린다. 30자 안으로 맞춰 두면 둘 다 문제없다)

**소개** (한도 150자, 줄바꿈 포함 137자):
```
The last convenience store before the edge of the universe.
Two night-shift clerks. Every customer is a problem.
New episodes 3x a week ↓
```

**링크:** 유튜브 채널 주소 하나. 인스타는 링크를 여러 개 넣을 수 있다는 자료도 있지만, 하나만 두는 게 클릭이 덜 흩어진다.

**계정 유형:** 크리에이터, 카테고리 "Artist" 또는 "Video Creator".

**하이라이트:** `CAST`(캐릭터 소개 카드 4장), `S1`(에피소드 목록). 첫 화가 나온 뒤에 만든다.

**릴스 캡션 형식:** 유튜브 쇼츠 설명과 같은 문장, 해시태그 3~5개. 인스타는 AI 정보 표시를 켠다(목소리가 합성이므로).

## 4. 배너·프로필 문구

- 배너 큰 글자: `VOID MART`
- 배너 작은 글자: `OPEN UNTIL THE HEAT DEATH OF THE UNIVERSE`
- 프로필 사진: 가게 네온 간판의 "O"를 원형으로 잘라 쓰거나, 두 주인공이 계산대 뒤에 선 얼굴 컷. 캐릭터 시트가 확정된 뒤에 그린다.

## 5. 작가님이 직접 할 일

1. 유튜브 스튜디오 > 맞춤설정 > 기본 정보: 이름, 핸들, 설명을 바꾼다. 핸들 변경 횟수 제한(14일에 2회라는 자료가 있으나 확인 못 함)이 있을 수 있으니 한 번에 정한다.
2. 인스타 계정을 같은 사용자 이름으로 만들고, Metricool의 Paper Almanac 브랜드(7923229)에 연결한다.
3. Metricool에서 브랜드 이름을 "Void Mart"로 바꾼다(브랜드 번호는 그대로라 예약 설정은 안 바뀐다).
